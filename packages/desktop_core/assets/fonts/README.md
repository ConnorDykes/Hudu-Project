# Inter

Inter variable font by the Inter Project Authors, distributed under the SIL Open Font License 1.1. The accompanying `OFL.txt` is the original license.

Source: [Google Fonts Inter distribution](https://github.com/google/fonts/tree/main/ofl/inter). Downloaded September 10, 2026. The font is bundled for consistent offline desktop typography; the apps do not fetch fonts at runtime.

# JetBrains Mono

JetBrains Mono Regular by JetBrains, distributed under the SIL Open Font License 1.1 (`JetBrainsMono-OFL.txt`). Source: [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono), downloaded September 10, 2026. Used for addresses, identifiers, and timestamps so tabular data renders identically on macOS and Windows.
